O projeto

CAA: Comunicação Aumentativa e Alternativa para autistas. Trabalho de Conclusão de Curso do Ensino Médio Integrado ao Técnico em Informática para Internet (Etec, 2026).

Autores: Giovanna Caroline Ferreira Vieira, Gustavo Henrique Zamparo Vieira, Gustavo Sanches Alves, Isadora Luana Fornarolli e Maria Clara Aquino. Orientador: Prof. Dr. Carlos Alberto Diniz.

Figuras

Figuras recortadas do arquivo “Flipbook PCS – ORIGINAL.pdf” fornecido pelo grupo. Autoras: Fabiani M. Eggers e Renata Bonotto; adaptação: Associação Comunicatea. PCS / Boardmaker: Tobii Dynavox.

O PDF informa “VENDA PROIBIDA” e uma permissão específica à Associação Comunicatea. O uso neste projeto é acadêmico e sem fins lucrativos; para qualquer uso além do TCC, confirme a autorização dos detentores dos direitos.

Cores das bordas

As bordas seguem a chave de cores de Fitzgerald: rosa para expressões sociais e preposições, amarelo para pessoas, verde para ações, laranja para substantivos, azul para qualidades, roxo para perguntas, marrom para advérbios, vermelho para recusa, ajuda e desconforto, e cinza para outros símbolos.

Dados e privacidade

O login é feito pelo Supabase Auth (Google ou e-mail e senha). As senhas são guardadas criptografadas pelo Supabase e nunca ficam nas tabelas do projeto. Cada pessoa só consegue ver as próprias frases (regras de segurança por linha, RLS). A voz é gerada pelo próprio navegador; as frases não são enviadas para serviços de voz.

Importante

Este é um projeto acadêmico, sem validação clínica. As figuras PCS não equivalem, por si só, à aplicação do protocolo PECS. A adaptação para cada pessoa deve ser orientada por profissionais.
